# هلا احمد — تطبيق تكسي (نسخة تجريبية)

موقع تجريبي من صفحة وحدة (`index.html`)، تفتحه بأي متصفح بدون تثبيت أي شي.

- **اطلب رحلة**: خريطة البصرة، اختيار نقطة الانطلاق والوجهة (أو الضغط على الخريطة)، أنواع الرحلات والأسعار، البحث عن سائق، حركة السيارة، التقييم والإكرامية.
- **الدفع**: محفظة هلا مع الشحن، طرق الدفع، إضافة بطاقة مع التحقق، سجل العمليات.
- **حساب الزبون**: البيانات الشخصية، الأماكن المحفوظة، سجل الرحلات.
- **السائق**: متصل/غير متصل، طلبات رحلات جديدة (قبول/رفض)، الأرباح، بيانات السيارة والمستمسكات.

كل البيانات تجريبية وتنحفظ بالصفحة فقط.

## التحديث الأخير

- كل شي صار برابط واحد (`index.html`)، والخريطة الحقيقية للبصرة داخل صفحة طلب الرحلة. `map.html` ينقلك تلقائياً للتطبيق.
- ملف الكابتن: الصورة، التقييم، عدد الرحلات، سنوات الخبرة، السيارة واللوحة، آراء الزبائن، والتحقق والأمان.
- أثناء الرحلة: اتصال، رسائل سريعة، مشاركة تفاصيل الرحلة، وأرقام الطوارئ.
- كود خصم (HALA10)، مدح الكابتن بعد الرحلة، دعوة صديق، والدعم.
- صورة الكابتن: ارفعها باسم `assets/captain.jpg`.

مكتبة Leaflet موجودة داخل `vendor/leaflet` (رخصة BSD-2).

## تطبيق الكابتن

رابط منفصل: `captain.html` (رابط الزبون `index.html` يعرض تطبيق الزبون فقط):
- **الدوام:** بدء ونهاية الدوام، خريطة بيها مناطق الطلب العالي، طلبات بعداد 15 ثانية (قبول أو رفض)، الطريق للزبون مع زر يفتح خرائط Google أو Waze، "وصلت"، عداد الانتظار، بدء الرحلة وإنهاؤها، استلام الكاش، وتقييم الزبون.
- **الأرباح:** صافي اليوم والأسبوع، عمولة هلا 15%، الإكراميات والمكافآت، الرصيد والتحويل لزين كاش أو البنك.
- **رحلاتي** و**حسابي:** السيارة، الإعدادات، والمستمسكات.
