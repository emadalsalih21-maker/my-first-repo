# هلا احمد — تطبيق تكسي (نسخة تجريبية)

موقع تجريبي من صفحة وحدة (`index.html`)، تفتحه بأي متصفح بدون تثبيت أي شي.

- **اطلب رحلة**: خريطة البصرة، اختيار نقطة الانطلاق والوجهة (أو الضغط على الخريطة)، أنواع الرحلات والأسعار، البحث عن سائق، حركة السيارة، التقييم والإكرامية.
- **الدفع**: محفظة هلا مع الشحن، طرق الدفع، إضافة بطاقة مع التحقق، سجل العمليات.
- **حساب الزبون**: البيانات الشخصية، الأماكن المحفوظة، سجل الرحلات.
- **السائق**: متصل/غير متصل، طلبات رحلات جديدة (قبول/رفض)، الأرباح، بيانات السيارة والمستمسكات.

كل البيانات تجريبية وتنحفظ بالصفحة فقط.
